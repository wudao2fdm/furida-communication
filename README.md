# Furida

基于 HTML 的家庭账单管理系统 —— 本地私有化、无需网络、数据隐私安全、简单易用，支持一键导出 Excel 表格。

An HTML-based home billing management system — fully local, no internet required, private and secure, easy to use, with one-click Excel export.

## 特性 / Features

- **本地私有化**：账单数据只保存在你自己的电脑上，绝不外传
- **无需网络**：完全离线运行，不上传任何数据
- **简单易用**：无需安装任何软件，打开即用
- **智能分析**：通过精美图表可视化家庭收支
- **导出 Excel**：账单一键导出为 Excel 表格，便于备份与分析

Fully local & private / Works offline / No installation / Smart charts / One-click Excel export
